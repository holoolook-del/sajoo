# SPEC: SAJOO — 나의 한국식 사주

## 한 줄 정의
본인(개인 사용자 1명)이 생년월일시로 한국식 사주(만세력 정밀 계산)를 풀이받고, 매일 운세카드를 게임처럼 화려하게 뽑아 확인하는 완전 오프라인 개인용 PWA.

## 사용자와 권한
- 본인(유일 사용자): 프로필 등록·수정, 사주 풀이, 오늘의 운세, 운세카드 뽑기(하루 1장), 대운·세운·월운, 궁합(상대 정보 그때그때 입력·미저장), 30일 히스토리
- 로그인 없음, 권한 모델 없음. 데이터는 기기 로컬 소유

## 핵심 흐름
1. 첫 접속 → 프로필 입력(이름/생년월일시·양력음력/성별) → 만세력 사주 계산 → 풀이 표시
2. 홈 → 오늘의 운세 → 당일 일진×내 사주 조합 운세
3. 홈 → 운세카드 뽑기 → 화려한 뽑기 연출 → 오늘의 카드+해석 (하루 1장) ← 존재 이유
4. 메뉴 → 대운(10년)·세운(올해)·월운(이번 달) 조회
5. 궁합 → 상대 생년월일시 입력(미저장) → 궁합 점수·해석
6. 기록 → 최근 30일 카드·운세 다시 보기

## 화면 / 인터페이스 (경로: 구성요소 / 상태)
- `/onboarding`: 프로필 입력 폼 / 빈 상태: 최초 접속 시 자동 표시 / 로딩: 계산 중 표시 / 에러: 필드별 검증 메시지
- `/` (홈): 오늘 날짜·일진, 카드 뽑기 CTA, 메뉴 / 빈 상태: 프로필 없으면 `/onboarding`으로
- `/saju`: 사주팔자 표·오행 균형·십신·종합 풀이 / 시주 없으면 3주 표기+안내
- `/today`: 오늘의 운세(총평·길흉 등급·조언)
- `/card`: 카드 뽑기 연출 → 결과 / 뽑은 날: 오늘 카드 다시 보기
- `/luck`: 10년 대운 흐름 표 + 현재 대운·세운·월운 풀이
- `/compat`: 상대 정보 입력 → 궁합 결과 / 종료 시 상대 정보 폐기
- `/history`: 최근 30일 카드·운세 목록 / 빈 상태: "아직 뽑은 카드가 없어요"
- `/profile`: 프로필 보기·수정
- 공통: 로딩 스켈레톤 / 에러·빈 상태 StateView(재시도) / 360px~ 레이아웃 유지 / 한국 전통 화려풍(단청·민화·한지 질감, 다크 배경+금박·광원 효과)

## 데이터
- `Profile`: `v`, `name`(1~10자), `calendar`('solar'|'lunar'), `isLeapMonth`, `year`(1900~2100), `month`, `day`, `hour`(0~23|null), `minute`(0~59|null), `gender`('male'|'female'), `createdAt` — 키 `sajoo:profile`
- `CardDraw`: `v`, `date`(KST 'YYYY-MM-DD'), `cardId`, `drawnAt` — 키 `sajoo:card:{date}`, 하루 1장 유일
- `FortuneRecord`: `v`, `date`, `iljin`, `grade`, `summary` — 키 `sajoo:fortune:{date}`
- 소유자: 본인 기기(localStorage) / 삭제: 브라우저 데이터 삭제 시 완전 삭제 / 30일 초과 기록 자동 정리
- 기존 데이터 이전: 없음 / 내보내기·백업: 범위 밖

## 규칙과 예외
- 생시 모름: `hour=null` → 시주 제외 3주(연·월·일) 계산 + '시주 미입력' 안내
- 음력 입력: 윤달(`isLeapMonth`) 지원, 라이브러리 변환
- '오늘'의 경계: 자정 KST 기준 전환(카드 리셋·일진). 사주 일주 경계는 라이브러리 야자시 관법 적용
- 카드 재뽑기: 당일 불가, 오늘 카드 다시 보기만
- 입력 오류: 미래 날짜, 범위 밖 연도(라이브러리 지원 범위), 존재하지 않는 날짜(2/30 등) → 저장 차단 + 안내
- 프로필 없이 기능 접근: `/onboarding`으로 이동
- 오프라인: 모든 기능 정상(완전 번들)
- 저사양 기기: 카드 연출은 GPU 가속 transform 위주, 무거운 파티클·블러 최소화
- 동시 수정: 단일 사용자라 해당 없음

## 비기능
- 지원 환경: 모바일 브라우저 360px 이상, Android Chrome·iOS Safari, PWA 설치 + 완전 오프라인
- 성능: 카드 연출 60fps 목표(저사양 단순화), 이미지 lazy 로드로 첫 로드 최소화
- 언어·시간대: 한국어 전용, Asia/Seoul 고정
- 접근성: 기본 명암대비·터치 타겟 44px (공식 접근성 인증은 범위 밖)

## 범위 밖 (절대 만들지 않을 것)
- 회원가입·로그인 / 서버 DB·계정 동기화 / 결제·구독 / 푸시 알림 / AI 채팅 상담·런타임 AI 해석
- 타인 프로필 저장 / 다국어 / 태블릿·데스크톱 전용 레이아웃 / 소셜 공유 링크·결과 이미지 생성 / 데이터 백업·내보내기

## 위험 등급
- 낮음: 화면 구성, 스타일, 풀이문 텍스트, 카드 데이터, 입력 폼
- 중간: 만세력 라이브러리 연동, 대운·세운·일진 조합 로직, 궁합 로직, PWA 오프라인, storage 스키마, 이미지 생성 스크립트, Pages 배포
- 높음(승인 필요): 없음 — 결제·인증·운영 DB·권한 모델·암호화·계정 삭제 전부 해당 없음

## 인수 기준 (AC)
- [AC1] Given 미등록, When 첫 접속, Then /onboarding 표시
- [AC2] Given 생년월일시·성별 입력(음력·윤달 포함), When 저장, Then KASI 기준 사주팔자 표시
- [AC3] Given 생시 미입력, When 저장, Then 3주 풀이 + '시주 미입력' 안내
- [AC4] Given 등록됨, When /today, Then 당일 일진×내 사주 조합 운세 표시
- [AC5] Given 당일 미뽑기, When 카드 뽑기, Then 뽑기 연출 후 카드+해석 표시·기록 저장
- [AC6] Given 당일 이미 뽑음, When 뽑기 시도, Then 차단 + 오늘 카드 다시 보기
- [AC7] Given 완전 오프라인, When 전 화면 사용, Then 모든 기능 정상
- [AC8] Given 상대 정보 입력, When 궁합 실행, Then 점수+해석 표시, 종료 후 상대 정보 미저장
- [AC9] Given /luck 진입, When 조회, Then 10년 대운 흐름 + 현재 대운·세운·월운 풀이
- [AC10] Given 과거 기록 존재, When /history, Then 최근 30일 목록 표시
- [AC11] Given 미래 날짜·범위 밖 연도·없는 날짜, When 저장 시도, Then 오류 안내·미저장
- [AC12] Given 360px 폭, When 전 화면, Then 레이아웃 깨짐 없음

## 사용자 원문 답변 요약
- "사주앱을 만들고싶어. 한국기준으로. 시중에 있는 사주앱만큼 퀄리티가 좋았으면해. 이미지도 생성해서 인터랙티브했으면해."
- "운세카드를 뽑는 연출, 마치게임처럼 화려하게"
- MVP 기능: "전부다해주면 좋을거 같아" — 사주팔자·오늘의 운세·대운세운월운·궁합·카드 전부
- 해석: 준비된 풀이문 DB / 전부 미리 생성·번들 / 궁합 상대는 그때그때 입력 / 생시 모르면 3주
- 이미지: Gemini API로 개발 중 생성(1만원 이하) / 카드 하루 1장 / GitHub Pages(공개 저장소 확인 완료) / 기록 30일
