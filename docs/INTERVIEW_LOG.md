## Stage 1 답변 (진행 중)

- 1-B MVP 기능: **전부** — "전부다해주면 좋을거 같아" (사주팔자 풀이 + 오늘의 운세 + 대운·세운·월운 + 궁합 + 운세카드)
- 1-C 해석 방식: **준비된 풀이문 DB** (LLM 실시간 해석 아님)
- 1-D 콘텐츠 공급: **전부 미리 생성·번들** — 런타임 API키/비용/인터넷 불필요, 완전 오프라인
- 1-E 궁합 상대: **그때그때 입력** (저장 안 함, '본인만' 유지)
- 1-F 생시 모름: **시주 없이 3주(연·월·일)로 계산 + 안내 표시**
- 1-G 이미지 제작: **AI 이미지 API로 개발 중 생성 후 번들**
- 1-H 운세카드: **오늘의 운세 카드** (하루 운세와 연동)
- 1-I 디자인: **한국 전통 화려풍** (단청·민화·한지 + 금박, 다크 배경 + 화려한 광원)
- 1-J 이미지 API: **Google Gemini** (개발 중에만 사용)
- 1-K 비용 상한: **1만원 이하** (1회성 개발 비용)
- 1-L 카드 규칙: **하루 1장** (자정 KST 리셋)
- 1-M 배포: **GitHub Pages** (공개 저장소 필요 — 최종 확인 시 재안내)
- 1-N 운세 기록: **최근 30일 히스토리**
